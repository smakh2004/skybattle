# Sky Blitz

Online top-down air combat built with [Rive](https://rive.app). Type a name, pick a plane, join the sky.

Play: https://smakh2004.github.io/skybattle/

Controls: **A/D** turn · **W/S** throttle · **Space** or mouse fire · **Esc** menu. Phones get a joystick and a FIRE button.

Multiplayer runs on Firebase (anonymous sign-in + Realtime Database). Locally: `python serve.py` and open http://localhost:8080.
